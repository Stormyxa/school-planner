# 🚀 Инструкция по деплою и запуску «Школьной Планёрки»

Добро пожаловать в руководство по развёртыванию приложения. Ниже описан каждый шаг простым и понятным языком.

---

## 📌 ШАГ 1: Загрузка проекта на ваш GitHub

1. Откройте терминал (PowerShell или Git Bash) в папке проекта:
   ```bash
   cd D:\AntiGravity\Projects\school-planner
   ```

2. Инициализируйте Git (если еще не инициализирован):
   ```bash
   git init
   git add .
   git commit -m "Первый релиз: Школьная Планёрка v1.0"
   ```

3. Создайте новый **публичный или приватный** репозиторий на [GitHub.com](https://github.com/new), например: `school-planner`.

4. Привяжите его и отправьте код:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Stormyxa/school-planner.git
   git push -u origin main
   ```

---

## ☁️ ШАГ 2: Бесплатный деплой на Vercel (Free Plan)

1. Перейдите на [Vercel.com](https://vercel.com/) и войдите через ваш GitHub-аккаунт.
2. Нажмите **«Add New...»** ➔ **«Project»**.
3. В списке репозиториев найдите `school-planner` и нажмите **«Import»**.
4. В поле **Framework Preset** автоматически определится `Vite`.
5. Нажмите кнопку **«Deploy»**.
6. Через ~40 секунд ваш сайт будет доступен в Интернете по адресу:
   `https://school-planner-xxxx.vercel.app` 🎉

---

## 📁 ШАГ 3: Настройка безлимитного хранения файлов (GitHub Storage)

Чтобы не тратить лимит бесплатного Supabase (500 МБ):

1. Создайте на GitHub отдельный репозиторий для документов школы (желательно **Private**):
   Например: `school-archive-storage`.
2. Создайте GitHub Personal Access Token (PAT):
   - Перейдите в **GitHub** ➔ **Settings** ➔ **Developer Settings** ➔ **Personal access tokens** ➔ **Tokens (classic)**.
   - Нажмите **«Generate new token (classic)»**, отметьте галочку `repo` (доступ к репозиториям).
   - Скопируйте полученный токен (начинается на `ghp_...`).
3. В панели проекта на **Vercel** перейдите в:
   **Settings** ➔ **Environment Variables** и добавьте две переменные:
   - `GITHUB_STORAGE_REPO` = `Stormyxa/school-archive-storage`
   - `GITHUB_STORAGE_TOKEN` = `ваш_токен_ghp_...`
4. Нажмите **Redeploy** на Vercel. Теперь все файлы учителей будут автоматически и навечно сохраняться в вашем GitHub-архиве!

## 🗄️ ШАГ 4: Подключение базы данных Supabase (по желанию)

*Примечание: Приложение уже работает сразу из коробки в локальном автономном режиме! Но для постоянной синхронизации между разными устройствами подключите Supabase:*

1. Зайдите на [Supabase.com](https://supabase.com/) и создайте бесплатный проект (например `school-planner-db`).
2. В боковом меню откройте **SQL Editor** ➔ **New Query**.
3. Скопируйте и вставьте всё содержимое файла `supabase/schema.sql` из проекта и нажмите **«Run»**.
4. Перейдите в **Project Settings** ➔ **API** и скопируйте:
   - `Project URL`
   - `Project API anon key`
5. Добавьте их в файл `.env` на компьютере или в **Environment Variables** на Vercel:
   - `VITE_SUPABASE_URL` = `https://ваш-проект.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = `ваш_anon_key`

## 📱 ШАГ 5: Установка приложения как PWA на телефон директору

Приложение уже полностью подготовлено как Progressive Web App:
- **На iPhone (Safari):**
  1. Откройте сайт школы в Safari.
  2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
  3. Выберите пункт **«На экран "Домой"»**.
  4. Нажмите **«Добавить»**. На экране появится красивая иконка приложения без адресной строки браузера!

- **На Android (Chrome):**
  1. Откройте сайт в Chrome.
  2. Браузер сам предложит баннер: **«Добавить "Школьная Планёрка" на главный экран»** (или через меню `⋮` ➔ «Установить приложение»).

- **Пуш-уведомления:**
  В правом верхнем углу сайта нажмите кнопку **«Включить пуши»** и подтвердите запрос в браузере.
